## Matrix implementation reference

The core bundles Arduino_LED_Matrix **0.1.3**. `Arduino_LED_Matrix matrix; matrix.begin(); matrix.setGrayscaleBits(3); matrix.draw(frame);` sends a 104-byte grayscale frame (8 rows by 13 columns; values 0..7 at three bits). `draw` delegates directly to `matrixGrayscaleWrite`. A fixed glyph buffer and time-based scroll can avoid ArduinoGraphics text animation. This API observation is not a timing measurement. Source: [library metadata](https://github.com/arduino/ArduinoCore-zephyr/blob/1.0.0/libraries/Arduino_LED_Matrix/library.properties), [matrix header](https://github.com/arduino/ArduinoCore-zephyr/blob/1.0.0/libraries/Arduino_LED_Matrix/src/Arduino_LED_Matrix.h), [Basic example](https://github.com/arduino/ArduinoCore-zephyr/blob/1.0.0/libraries/Arduino_LED_Matrix/examples/Basic/Basic.ino).

`loadFrame` accepts four packed uint32_t words. Avoid the `renderBitmap` / `loadPixels` convenience path in this revision: inspection finds `_frameHolder[3]` while a 104-pixel conversion writes a fourth word; this is a source-level potential out-of-bounds defect, not a reproduced hardware failure. `playSequence` and the official text example use delays and are unsuitable as templates for the deterministic loop.

## Protected conflict requiring coordinator escalation

P0 0.2 requires a Monitor counter, while AGENTS R3 prohibits blocking Bridge calls and R4 prohibits post-setup String/allocation/unbounded work. Current official source contains those behaviors. Options: (A) approve a narrowly isolated inert P0 demonstration exception, with no reuse in match code; (B) approve development and verification of a bounded transport adaptation; (C) defer Monitor proof. Recommendation: C immediately, until the human selects A or B. A matrix-only sketch and RAM counter are partial P0 artifacts, not fulfillment of the Monitor round-trip gate. Required regression evidence: no inbound motion API; no Bridge use in control states; bounded failure behavior; no post-setup allocation; actual matrix/counter round trip when finally authorized and implemented. No option is approved by this analysis.
