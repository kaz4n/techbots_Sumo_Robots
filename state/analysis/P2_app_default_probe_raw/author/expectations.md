# D118 independent executable expectations

Derived from the adopted public contract and its pre-execution output lifecycle
clarification, public Runtime/Transaction headers, saved exact ABI, and unchanged
heap vector/helper contracts. This reused author context earlier inspected app
source for eligibility; it has not read the prospective app_default_capture.py
body. No cross-model or fresh-repository independence is claimed.

The new 40-method suite uses literal 28/24-byte prefix recipes and exact report
keys, all valid enum combinations, every invalid enum/bool field, immutable-byte
extent/type rejection, unknown-versus-known Transaction tri-state, and honest
live-progress/fault/malformed precedence. Padding and incoherent live timestamps
remain observations rather than invented transaction consistency requirements.

Collector recipes generate the existing independently authored valid heap bytes
in RAM. Default nodes are at HEAP_BASE+200000, +200256 and +200512; default BSS
starts at HEAP_BASE+88, allowing literal alignment slack after the used chunk's
4-byte header. Full pool payload and independently read app/node snapshots are
not required to be atomic or equal. Negative cases cover free/invalid allocation,
whole-BSS escape despite fitting Runtime, exact endpoint containment, descriptor
and metadata change, malformed graph/name/selected-node fields, and unchanged
full nodes/list after observation. Three unrelated terminated non-UTF8 names are
valid absence and their BSS/header fields remain opaque.

Every actual subprocess request is checked against the literal four metadata
argv followed by the exact ordered memory addresses/sizes. A counted fake
subprocess writes actual returned raw files and never executes copied tools.
The real p0 file/hash/no-symlink/range/image helpers and real heap decoder run
unchanged. Only standard Path/filesystem, subprocess and monotonic clock calls
are mapped. Exact copied ELF/ZSK, loader and tool binaries supply identity bytes;
no expected hash or production helper is substituted. Each refused arbitrary
operation uses a separate capture, without private-state initialization.

All 16 flash blocks are mutated at both byte endpoints; present/absent paths,
live payload changes, partial transport output, late exit0, exact600-second
boundary, validation time, command timeout remaining time, single-attempt
poisoning, fresh directory ownership and actual CLI JSON/exit outcomes are
covered. Higher64-read/80-command ceilings are unreachable under the admitted
62-read/66-command plan; tests execute the plan and forbidden extra/replayed
purposes rather than seeding counters. No transient loader headroom, atomic
sample, WCET, physical inhibition, hardware origin or phase-gate claim follows.

The isolated harness copies opaque source and exact fixtures to /dev/shm, then
runs the new suite plus the unchanged heap-helper tests. It retains small source
hash manifests, stdout and receipts instead of hundreds of full-pool duplicates.
No module import or executable test has occurred before first_test_freeze.json.
