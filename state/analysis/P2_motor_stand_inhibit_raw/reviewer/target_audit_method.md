# D115 exact-default target audit method (prepared; artifacts pending)

This is a bounded application of the existing D098/D106/D114 ELF decoder and installed-loader model, not target evidence. No board command, production import/execution, test run or new modeling framework is needed for this preparation. D115 only permits the false-grant, default-startup, MATCH0/MOTORS_ALLOWED0 image; there is no upload key or run approval.

1. Bind the collected checked receipt to its literal `motor_stand.ino`, base FQBN, inert flags, default startup, unique checked build/artifact directory and exact compile argv. Revalidate successful preflight/compiler JSON with the existing policy, resolved configuration directories, installed hashes and empty libraries. Require all retained command statuses and stderr to support collection success; preserve failures.
2. Rehash every byte of the immutable95-file source tree and recompute the established ordered source hash. Require exactly90 unchanged shared files plus the five first-frozen motor_stand files, with no HAL/core/config change or stray copied sketch. Bind all three ELF files and ZSK bytes to the checked receipt and collector hashes. A future file-count/source change needs explicit disposition rather than silently widening this set.
3. Decode ELF32 little-endian ARM ET_REL directly with the existing `state/reviews/P2_bridge_dependency_review_raw/elf_review.py`; cross-check retained readelf/nm/objdump evidence. Inventory section type/flags/alignment/size, symbol binding/type/index/value, all relocations, constructors/finalizers and strong startup hooks for final/debug/temp images. Treat only final ELF/ZSK as the deployment candidate; temporary/debug accounting is labelled separately.
4. Require actual default startup: core main calls the reviewed `initVariant`, empty static-thread starter, setup, loop and empty loop hook. Confirm `initVariant` and `__loopHook` resolve to the expected empty implementations; no new strong override or populated static thread bounds. Inventory every init/preinit/fini entry, not just the first. Expected sole sketch initializer builds one Native/Port and one Runner/Gate; no callback, clock, pin, timer, heap or peripheral action may occur on that path.
5. Inspect actual setup machine code and relocations: construct a false Grants value and call Runner.begin once. Trace the false branch through attempted-state consumption to DISABLED without Gate.begin/fault/halt or native callbacks. Loop must reach only passive poll. Inspect Runner constructor, Native.port and UnoQPort.port/candidate-period helpers: only state copy/initialization and constant/device-tree arithmetic; no native register loads or calls concealed in startup. Do not infer passivity merely from MOTORS_ALLOWED0.
6. Inventory retained callbacks/imports separately from executed startup. Retained GPIO/PWM/pinctrl/clock/readiness helpers are expected through the existing UnoQPort function pointers; bind each to the unchanged reviewed motor source and actual port slots. Reject unexplained owners, constructors, hooks or imports. No Robot/Runtime, apply/reset/token producer, Bridge/router/UART/Serial, matrix, QTR, opponent, ADC/battery or I2C/IMU owner may become an active/retained dependency accidentally. Distinguish unused imported declarations from relocation-used symbols. Resolve every used external against the pinned loader export evidence and accepted device descriptors.
7. Confirm the exception allocation shim is the reviewed abort stub, not an allocating execution path; no dynamic new/malloc/realloc/free use or indirect allocation from constructors/setup. Existing empty static-thread-start code is not a created thread. Inspect actual callback binding and startup reachability instead of using a blanket symbol-name ban.
8. Recheck the sole shared70-entry/560-byte immutable native pin table against D106 bytes and relocation records. Verify TABLE pointer/addend and COUNT70; no duplicate referenced table or mutable substitute. Any retained PWM/PAD/device-tree descriptor is metadata, not a granted hardware action, and must agree with unchanged motor source/mapping.
9. Derive actual ARM ABI from the exact debug ELF: Runner, Native, Report, HaltResult and Port sizes/alignment/member offsets; one Gate and one native owner; enum/boolean widths and complete HaltResult containment. Cross-check final symbols/BSS/data extents. Do not assume a report size, hardcode a RAM readout, or subtract nm's displayed section VMA from raw ET_REL st_value. There is no capture format in D115.

For the conditional loader fit, reuse the existing pinned32-bit non-Harvard256KiB LLEXT heap model and cached sources described in `state/analysis/P2_memory_loader_budget.md`. Require installed loader ELF SHA25639d4a4fd47241663323f6e04f94dd8f5a9f9ad6582cf1df37f9709b74026adcd and unchanged relevant configuration; otherwise stop and rederive assumptions. Verify persistent-flash peek alignment at0x08100010 for section headers, `.llext.rodata.noreloc`, symtab and strtab. Account all SHF_ALLOC copied regions except eligible no-reloc flash data, including prepadding/alignment/header costs.

Preserve an ordered allocation ledger: initial88-byte heap bookkeeping; extension object; section map; copied regions in actual loader order `.text`, `.data`, `.rodata`, `.bss`, `.exported_sym`, `.preinit_array`, `.init_array`, `.fini_array`; temporary global symbol table and exported-symbol copy. Explain any extra section instead of appending it silently to the final-image model. The existing small-chunk model uses8-byte granularity,4-byte allocation headers, the reviewed alignment8 case,196-byte extension payload and8-byte section/symbol metadata entries. Check every allocation against remaining contiguous span, not just a summed compiler payload. Report final payload, peak consumption, remaining span and largest payload with all assumptions.

This remains a pristine-pool, successful-peek, no-interleaved/constructor-allocation calculation. It does not establish an actual load, live free RAM/fragmentation, stack/WCET, electrical LOW/zero/coast, STAND OK, B4/B7 acceptance or a human phase gate. Any target/source/hash drift, unknown initializer/import, active false-grant path, ABI inconsistency or allocation failure prevents a scoped target PASS. Execute this audit only after the coordinator provides the exact checked artifact set and frozen executable-test evidence.
