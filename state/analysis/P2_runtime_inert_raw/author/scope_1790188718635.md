# D104 independent test scope

Derived from frozen D104 contract/public headers and D075 MotorGate contract, without reading any production/bench implementation .cpp. Actual production sources are byte-copied opaquely into /dev/shm for g++ linkage. Default config is unchanged. No hardware or board tool commands; no shared build; no existing test/CMake/source edit.

Public boundary coverage: full 200-second clock window at ordinary uint32 values and across natural wrap, at most one actual Runtime epoch per poll, canonical absent physical sources, BOOT and EMPTY retention, actual finished Transaction and matched Gate receipt, genuine S/D/A/C observations, first and last epoch, report/diagnostic 192/232-byte ABI, callback counters, zero/active/invalid direct inert port requests, setup ordering, one-shot begin, missing clock, exact first and overall deadlines, missed release, equal-clock stall and every observed callback position regression/half-range rejection, final passivity. Host simulated time is not MCU timing or physical qualification.

Limits: uint32 counter saturation is not realistically reachable through this fixed public one-shot probe without billions of callbacks or private-state seeding. 10000 direct zero transactions exercise monotonic counters but do not establish the UINT32_MAX boundary. Review must inspect saturating arithmetic separately. Runtime/Transaction/input/receipt faults that cannot be created by the public absent-source Runner are not fabricated by const-cast/private access. Clock failures are exercised at real callback seams and actual public faults retained. Probe maximum duration is not full-app WCET. Stack metadata/native ELF/physical capture qualification belongs to independent native review, not this host suite. Wrapped malloc/calloc/realloc/free detects those C allocation routes during begin/poll, not every possible external allocator.

Pre-run reads initially used two nonexistent guessed filenames (docs/prompts/P2_hal.md and src/core/inputs.h); corrected to P2_hal_bench.md and public core/types.h. No implementation was read as a workaround. Test logs preserve commands and all compile/runtime failures append-only.
